# Gaming Info Telegram Bot

Информационный телеграм бот для предоставления актуальной информации по играм HoYoverse и другим популярным играм.

## Возможности

- 🎮 **Информация об играх** - актуальные данные по поддерживаемым играм
- 📋 **Текущие баннеры** - информация о действующих баннерах и событиях
- 🔗 **Полезные ссылки** - ресурсы, гайды, карты и статистика
- 🔐 **Whitelist система** - контроль доступа к боту
- 🎨 **Удобный интерфейс** - эмодзи и интуитивная навигация

## Поддерживаемые игры

- 🌟 **Genshin Impact** - HoYoverse
- 🚀 **Honkai: Star Rail** - HoYoverse  
- ⚡ **Zenless Zone Zero** - HoYoverse
- 🌊 **Wuthering Waves** - Kuro Games

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd gacha_assistant_telebot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурацию в `config.py`:
```python
# Токен вашего бота от @BotFather
TELEGRAM_BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"

# Список пользователей с доступом (ID пользователей Telegram)
USERS_WHITELIST = [
    "123456789",  # Замените на реальные ID пользователей
    "987654321"
]
```

## Запуск

```bash
python main.py
```

## Команды бота

- `/start` - Запуск бота и приветствие
- `/help` - Справка по использованию
- `/menu` - Главное меню

## Навигация

**Главное меню** состоит из 4 кнопок с играми:
- 🌟 **Genshin** - Genshin Impact
- 🚀 **HSR** - Honkai: Star Rail
- ⚡ **ZZZ** - Zenless Zone Zero
- 🌊 **WuWa** - Wuthering Waves

При нажатии на игру сразу открываются **полезные ссылки** для этой игры из файлов `links/[game]/keyboard.py`.

## Особенности

- **Прямая навигация** - один клик от главного меню до ссылок игры
- **Модульная архитектура** - легко расширяемый код
- **Whitelist система** - бот работает только с авторизованными пользователями
- **Inline клавиатуры** - удобная навигация без перехода в меню
- **Обработка ошибок** - корректная обработка исключений
- **Логирование** - подробные логи для отладки
- **Готовность к расширению** - структура для добавления парсинга данных

## Настройка

### Получение токена бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `config.py`

### Получение ID пользователя

1. Найдите @userinfobot в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш ID в `USERS_WHITELIST`

## Разработка

Бот построен на библиотеке `python-telegram-bot` версии 20.7+ с использованием асинхронного API.

### Добавление новых игр

1. Добавьте информацию об игре в `get_game_info()` в `methods.py`
2. Добавьте данные о баннерах в `get_banner_info()`
3. Создайте папку `links/[game_name]/` с файлом `keyboard.py`
4. Обновите inline клавиатуры в `main.py`

### Работа с клавиатурами ссылок

Клавиатуры с ссылками хранятся в папке `links/[game_name]/keyboard.py`. Каждый файл должен содержать:

```python
from telegram import InlineKeyboardButton

keyboard = [
    [
        InlineKeyboardButton("Название кнопки", url="https://example.com"),
        InlineKeyboardButton("Другая кнопка", callback_data="callback_data")
    ],
    # ... другие строки кнопок
]
```

Бот автоматически загружает эти клавиатуры при выборе игры в разделе "Полезные ссылки".

### Добавление парсинга данных

Используйте существующую структуру в папке `data_parsing/` для добавления парсеров данных из игр.

### Добавление новых команд

1. Создайте обработчик в `main.py`
2. Добавьте команду в `update_commands()` в `methods.py`
3. Зарегистрируйте обработчик в функции `main()`
