# 🎮 Gacha Assistant Telegram Bot

Современный Telegram бот для геймеров с информацией о баннерах, событиях и полезными ссылками по популярным Gacha-играм.

## ✨ Возможности

- 🎯 **Актуальные баннеры** - текущие и предстоящие баннеры с изображениями
- 🔗 **Полезные ссылки** - гайды, карты, статистика, трекеры
- 🎨 **Генерация изображений** - красивые карточки баннеров
- 🔐 **Whitelist система** - строгий контроль доступа
- 👑 **Админ-панель** - управление пользователями и кешем
- 📊 **Статистика** - информация о кеше и состоянии бота
- 🚀 **Автообновление** - автоматическое обновление данных каждые 7 дней

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd gacha_assistant_telebot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурацию в `config.py`:
```python
# Токен вашего бота от @BotFather
TELEGRAM_BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"

# ID администратора бота (владелец, может управлять whitelist)
# Получите свой ID через @userinfobot или любым другим способом
ADMIN_ID = "YOUR_ADMIN_ID_HERE"

# Список разрешенных пользователей теперь хранится в файле whitelist.txt
# Используйте команды бота для управления whitelist
```

## Запуск

```bash
python main.py
```

## 📋 Команды бота

### Основные команды
- `/start` - 🚀 Запуск бота и приветствие
- `/help` - 🆘 Справка по использованию
- `/menu` - 🏠 Главное меню

### Информационные команды
- `/update_banners` - 🔄 Принудительное обновление баннеров
- `/banner_status` - 📊 Статус баннеров по играм

### Управление кешем
- `/clear_cache` - 🗑️ Очистить кеш изображений
- `/cache_stats` - 📈 Статистика кеша

### 👑 Админ-команды (только владелец)
- `/add_to_whitelist <id>` - ➕ Добавить пользователя в whitelist
- `/remove_from_whitelist <id>` - ➖ Удалить пользователя из whitelist
- `/show_whitelist` - 📝 Показать список пользователей
- `/update_commands` - ⚙️ Обновить команды в Telegram

## Настройка

### Получение токена бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `config.py`

### Получение ID администратора

1. Найдите @userinfobot в Telegram
2. Отправьте любое сообщение боту
3. Скопируйте полученный ID в `ADMIN_ID` в config.py

### Управление whitelist через бота

После настройки `ADMIN_ID` вы можете управлять списком разрешенных пользователей:

- `/add_to_whitelist <user_id>` - добавить пользователя
- `/remove_from_whitelist <user_id>` - удалить пользователя
- `/show_whitelist` - показать список пользователей

## Разработка

Бот построен на библиотеке `python-telegram-bot` версии 20.7+ с использованием асинхронного API.

### Добавление новых игр

1. Добавьте информацию об игре в `get_game_info()` в `methods.py`
2. Добавьте данные о баннерах в `get_banner_info()`
3. Создайте папку `links/[game_name]/` с файлом `keyboard.py`
4. Обновите inline клавиатуры в `main.py`

### Работа с клавиатурами ссылок

Клавиатуры с ссылками хранятся в папке `links/[game_name]/keyboard.py`. Каждый файл должен содержать:

```python
from telegram import InlineKeyboardButton

keyboard = [
    [
        InlineKeyboardButton("Название кнопки", url="https://example.com"),
        InlineKeyboardButton("Другая кнопка", callback_data="callback_data")
    ],
    # ... другие строки кнопок
]
```

Бот автоматически загружает эти клавиатуры при выборе игры в разделе "Полезные ссылки".

### Добавление парсинга данных

Используйте существующую структуру в папке `data_parsing/` для добавления парсеров данных из игр.

### Добавление новых команд

1. Создайте обработчик в `main.py`
2. Добавьте команду в `update_commands()` в `methods.py`
3. Зарегистрируйте обработчик в функции `main()`
